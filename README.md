# Show das Habilidades

Site educativo de Língua Portuguesa para 8º e 9º anos.

## Publicar no GitHub Pages
1. Extraia o ZIP.
2. Envie todos os arquivos e a pasta original para a raiz do repositório, mantendo a estrutura.
3. Em Settings > Pages, selecione Deploy from a branch, branch main e pasta / (root).
4. Salve e aguarde o GitHub disponibilizar o endereço.

Não é necessário instalar dependências ou executar build. O index.html fica na raiz.

## Recursos
12 questões, pontuação, progresso local, imagens ampliáveis, som opcional e tela cheia.
Os textos e alternativas foram preservados. A questão 11 foi sinalizada para revisão porque todas as alternativas levam à tela de erro no arquivo original.
O progresso é salvo somente no navegador utilizado.
As fontes do Google são opcionais: sem conexão, o site utiliza fontes do sistema.

## Arquivos
index.html: página inicial.
style.css: aparência.
app.js: interatividade.
questions.js: questões e gabarito extraídos da apresentação.
content.json e imagens: conteúdo original extraído.
original/: apresentação original em PPTX e PDF.
